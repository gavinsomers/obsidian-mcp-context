# obsidian-mcp-context

Public package for turning textual Obsidian Markdown into AI-ready context exposed through MCP.

Intended public scope:

- Textual Obsidian Markdown only.
- Synthetic demo vault only.
- Generic parsing, normalization, chunking, prompts, and MCP resources/tools.

Out of scope:

- Personal vault data.
- WhatsApp or private message processing.
- Calendar OCR.
- Business connectors such as Slack, HubSpot, and Google Workspace.

Migration source:

- Extract generic, publishable pieces from `gavin-knowledge-engine` after the private workflow has been separated.
